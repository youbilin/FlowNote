# 流量笺 · UI 设计规范（v0.3.1）

## 用户与任务

普通拼节点用户打开页面，直接了解剩余多少、上传下载各多少、总配额与何时到期。无需填写账号、UUID 或订阅链接。成功页只保留数据、状态、刷新和必要的曲线口径；帮助、统计延迟与部署说明放到文档。

## 信息架构

1. 品牌页头：流量笺 / FLOWNOTE。
2. 概览标题、当前账号、状态、刷新按钮。
3. 剩余流量大数字与使用进度；已用、总配额、上传、下载四个数据格。
4. 到期时间（标明时区）、最近在线。
5. 用量记录：上传 / 下载图例、日期横轴、累计字节纵轴；仅一行「查询采样 · 累计用量」说明。
6. 查询生成时间与版本。

无宣传语、FAQ、重复教程、通知长文、自动轮询或弹窗。

## 视觉语言

雾白背景、浅蓝余量卡、白色数据格、细边框和留白。蓝色表示上传，青绿色表示下载；系统深色模式切换为深灰蓝。系统字体与等宽数字，无外部字体、图片或脚本。桌面容器最大宽度 960px（含两侧内边距），640px 以下改为单列，320px 起可读。移动端坐标标签使用 HTML 固定字号，避免 SVG 缩放导致文字过小。

剩余流量为首要层级，上传下载与配额为次要层级。状态使用颜色和文字同时表达，刷新提供键盘焦点与明确无障碍名称。无配额上限时标明「无限配额」，不把空进度条解释成 0% 用量。

## 状态矩阵

| 状态 | 表现 |
| --- | --- |
| 正常 | 青绿色状态文字与圆点 |
| 已用 ≥90% | 状态为暖黄色；进度保持实际比例 |
| 已用尽 | 剩余 0、比例最高 100%、明确文字状态 |
| 已过期 / 已停用 | 明确状态，不另加说明长文 |
| 无限配额 / 无限有效期 | 显示「不限」/「不限期」 |
| 首次使用计时 | 显示「激活后 N 天」 |
| 历史不足两个点或存储不可用 | 显示「暂无历史记录」，当前数据继续展示 |
| 403 / 502 | 简短原因与「重新查询」链接 |

多个异常并存时优先级：停用 → 流量用尽 → 已过期。

## 曲线语义

仅用真实查询采样点，以实际时间间隔定位，不补齐日期、不伪造历史、不宣称精确每日账单。纵轴分别为累计上传、累计下载，共用刻度；任一计数下降时两条线都断开，表示可能发生重置。曲线由服务端生成内嵌 SVG，无外部图表依赖或前端脚本。刷新遵循面板缓存；缓存命中不会制造新采样时间。

## 交互与隐私

刷新为普通链接，页面由服务端渲染。无会话 Cookie、localStorage、第三方请求；响应禁止缓存、禁止 iframe，动态文本转义。历史记录存储在服务端，按服务端识别到的账号隔离；客户端不能用参数指定账号。账号是面板 email 标签，建议使用非个人信息别名。

## 可复现预览

```bash
cargo run --locked -- --preview output/preview
```

生成正常、低流量、用尽、过期、停用、不限、未激活、403、502 共九种合成页面。曲线为合成展示数据，未激活示例展示空历史；命令不启动服务或读取真实面板。生产与预览共用模板。
