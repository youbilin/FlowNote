# 流量笺 · UI 设计规范（v0.3）

## 用户与任务
普通拼节点用户只需要知道「还能用多少、何时到期、现在是否可用」。不展示面板配置，不需要订阅、登录、UUID 或输入账号，不做管理后台。

## 信息架构
1. 品牌页头：流量笺 / FLOWNOTE，提示私密查询。
2. 引导与刷新：用量有数，连接有度；手动刷新，不轮询。
3. 主卡片：最大字号展示剩余流量，辅以状态徽章、已用比例、总配额和当前账号。
4. 连接档案：账号状态、完整到期时间与时区、最近在线。
5. 上传 / 下载：两个独立小卡。
6. 提示：低流量（已用 ≥90%）与异常状态，明确统计延迟。
7. 常见问题：切换节点、配额与有效期；页尾显示查询生成时间，不冒充面板统计更新时间。

## 视觉语言
雾白背景、松绿色主卡、细边框与留白。数字使用等宽数字；系统字体栈，无远程字体、图片、脚本、分析 SDK。桌面最大宽度 1120px；720px 以下单列，320px 起可读。跟随系统深色主题，键盘焦点清晰，减少动画偏好下禁用过渡。

## 状态矩阵
| 状态 | 表现 |
|---|---|
| 正常 | 绿色徽章，剩余配额为主 |
| 已用 ≥90% | 暖黄提示，百分比保持真实 |
| 已用尽 | 剩余 0，进度最高 100%，提示联系管理员 |
| 已过期 / 已停用 | 文字状态 + 异常提示，不只靠颜色 |
| 无限流量 / 无限有效期 | 显示「不限」，不伪造 0% 用量含义 |
| 首次使用计时 | 明确「首次使用后 N 天」，不是具体到期日期 |
| 403 / 502 | 同一视觉框架的错误页，给出连接节点 / 刷新 / 联系管理员的操作 |

多种异常同时发生时显示优先级：停用 → 流量用尽 → 已过期。状态仅由面板字段决定。

## 交互与隐私
刷新为普通链接，成功页和错误页均服务端渲染；静态页面没有 JS，不存在空白加载期。请求等待由浏览器原生反馈。刷新会遵循服务端缓存 TTL，不能承诺实时或强制绕缓存。无会话 Cookie、localStorage、第三方网络请求；拒绝 iframe，响应禁止缓存。

HTML 将标题、账号及错误文案转义；账号字段是面板 email 标签，建议管理员使用非个人信息的别名。界面不宣称 VPN、匿名性或绝对安全。页面提及的 HTTPS 由服务端真实 TLS 提供，不根据用户可伪造的 X-Forwarded-Proto 显示安全标识。

## 可复现预览
```bash
cargo run --locked -- --preview output/preview
```
输出正常、低流量、用尽、过期、停用、不限、未激活、403、502 共 9 个合成页面。与生产使用同一渲染器；无真实用户数据。此命令不启动监听、不读日志或调用面板。
