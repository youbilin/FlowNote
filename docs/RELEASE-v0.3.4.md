# FlowNote v0.3.4 · 交互式卸载与清理

运行 `sudo flownote-setup`，选择 **5**：

- 选择 1，输入 `UNINSTALL`：卸载程序、菜单与服务，保留配置、Token、证书、历史、日志与备份。
- 选择 2，输入 `DELETE`：另行永久清除默认配置、Token、证书、历史和备份；可安全移除时清理专用日志、轮转及标准服务账号。

先核对并移除向导的查询出站 / 路由，测试和恢复 Xray 后才删除程序。保留原节点、面板设置与流量统计，失败 / 中断尝试恢复模板及原活动服务。自定义查询内容需先人工检查；日志仍被 Xray 使用时保留日志、轮转和账号。符号链接、挂载点和与面板目录重叠的清理目标被拒绝。

卸载前移除客户端规则；面板 API Token 撤销、自定义目录、共享日志 ACL 和系统 journal 需另行处理。完全清理不能撤销，包含备份与证书。

Linux amd64 / arm64 预编译包与带 SHA-256 校验的安装脚本已包含新版菜单。主应用 HTTP / HTTPS 与简约 UI 保持原有功能。卸载回归测试使用临时 SQLite / 文件与模拟系统命令，不代表已在用户服务器执行卸载。
